API 35 기본 560dpi, 411dp 폭, fontScale 1.0에서 라이트·다크 Compose 샘플을 네이티브 캡처했습니다. 범위는 문서가 있는 보관함입니다. API 35 QaSmokeJourneyTest에서 홈과 보관함을 거쳐 실제 문서를 편집기에 열고 뒤로 돌아왔습니다. 보관함의 필터와 홈의 긴 제목은 한·영 라이트·다크, 320~390dp, 글꼴 1~2배의 별도 렌더 테스트를 통과했습니다.
