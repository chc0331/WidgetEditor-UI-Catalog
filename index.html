MyWidget UI 카탈로그

Android 앱의 공통 조작과 실제 사용 화면을 탐색합니다.

디자인 원칙

위젯 미리보기를 편집의 중심에 두고 조작은 필요한 곳에 배치합니다. Material 3 테마의 역할을 사용하고 중립 표면, 얇은 테두리, 파란 강조로 위계를 전달합니다.

컴포넌트 선택

테마 토큰으로 앱 전체의 의미를 맞추고, 같은 조작·상태 계약은 공통 컴포넌트로 사용합니다. 표준 Material 컨트롤로 계약을 충족할 수 있으면 그대로 사용합니다. 화면의 제품 상태·네이티브 입력과 연결되는 배치는 해당 기능이 소유합니다.

변경할 때는 실제 호출처, 라이트·다크, 글꼴 확대, 조작과 접근성, 런처 위젯과의 공유 의존성을 확인합니다.

조사 범위
